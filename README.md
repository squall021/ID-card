# ID-card

名牌製作／識別證套印工具。

功能包含：正反面版型、Excel 套印、固定文字、QR Code、八方向縮放、智慧對準線與邊界吸附、自動縮字、輸出份數設定，以及 PNG / PDF / A4 拼版匯出。

此專案為純前端網頁，適合透過 GitHub Pages 使用。

## 開啟方式

解壓縮後可在 Chrome 開啟 `index.html` 試用。部署時將整個資料夾的內容放到 GitHub Pages 發布目錄，保留 `vendor/`、`.nojekyll` 和相對路徑。透過 HTTP 或 HTTPS 開啟時，大檔名單會優先在背景執行緒解析。

## 版型與輸出

- 匯入支援既有 V3 單面與 V4 正反面版型。版型中的文字和支援的樣式會重建，底圖與 Logo 使用原工具內嵌的圖片資料。自行加入的外部圖片網址和自訂 HTML 標記會被移除。
- Excel 取第一張工作表。套印欄位已有同名原始欄時，優先取同名欄。份數設定選擇 Excel 的原始欄位。
- A4 正反面 ZIP 含兩份 PDF，正面與背面使用相同的格位順序。以「實際大小／100%」列印，再依印表機的進紙及翻面方式核對正背對位。
- 第三方程式檔隨網站一起提供。請參考 [版本、來源及授權](vendor/README.md)。
